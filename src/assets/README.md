# Official AGS logo goes here

Save the school's official logo in this folder as one of:

- `ags-logo.svg` (best — sharp at every size)
- `ags-logo.png` / `ags-logo.webp` / `ags-logo.jpg` (use a transparent or white background, at least 300 px tall)

The header picks it up automatically (see `AGS_LOGO` at the top of `src/App.jsx`); until then it shows the
school's name as text. Rebuild the offline file afterwards with `npm run build:single`.
